## Framing
A is an event-semantics problem, not a file-diff utility; B is a human-owned interactive channel, not another autonomous subprocess. Fix those contracts before choosing transport.

**Q1.** Fold a monotonic, append-only, closed-vocabulary event journal plus the existing detached judgement: status/member transitions, liveness-derived `died`, unreadable records, and foreign-host runs as `unknown`, never as quiet. Use `--since <sequence>`, not a wall-clock instant. Do not fold worker STATE prose.

The cheapest reliable schedule is `min(cache-TTL ceiling, periodic liveness deadline, real operator/run deadline)`, with jitter; budget end and quota reset are advisory upper bounds, not completion events. A watch-first wake only shrinks action tokens: the host still supplies cached context. Removing the heartbeat can cold the cache; silent death can masquerade as no change.

**Q2.** Put adapters in C3 (B'). A browser-loaded catalogue conflicts with MV3: Chrome disables WebAssembly under the default extension CSP and requires `wasm-unsafe-eval` for the minimum enabling policy, while remotely fetched WASM is remote-hosted code ([CSP](https://developer.chrome.com/docs/extensions/reference/manifest/content-security-policy), [remote code](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code)).

Prefer native messaging to a loopback WebSocket: Chrome starts a bound native host and speaks stdio, with non-wildcard `allowed_origins` and port-scoped lifetime ([native messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)). Minimal host API: verify catalogue/signature/revocation; begin a session bound to adapter hash, origin, tab, mode, capabilities and consent; draft composer; subscribe/read only the bound thread; explicit `send`; append audit; end session. Every bridge operation carries the per-run capability and refuses unmatched origin/tab.

**Q3.** Persist an interactive run record: `created`, `relay-connected`, `tab-bound`, `draft-written`, `awaiting-send`, `sent`, `streaming`, `parsing`, then exactly one terminal class: `completed`, `not-sent-expired`, `user-declined`, `tab-closed`, `relay-lost`, `extension-disconnected`, `abandoned-by-operator`, `partial-salvaged`, or `failed`. `awaiting-send` pauses stall/timeout and has its own consent expiry. Stop means record plus abandon/disconnect and partial salvage—never close the user’s tab. Do not seat draft-only browser reviewers in unattended detached runs or concurrent panels by default.

**Q4.** Omitted designs: the event journal; native messaging; a separate adapter-host process; an explicit cache-keepalive path; adapter rows keyed by content hash. To choose, measure host cache TTL/cached-input cost, actual silent-death rate, Chrome context/CSP behavior, native-messaging concurrency and service-worker lifetime, extension update controls, vendor autosave/terms, and user availability.
