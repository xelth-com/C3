# Framing

The brief treats (A) and (B) as two measurement designs. They are one decision: both need the same two axes - a normalized effort token and an actor/tier class - added to a closed vocabulary. Decide that once, not twice.

Options the brief does not list: (O5) record nothing new now - the local ledger already holds `effort`, `effort_requested`, `effort_mapping`, `effort_caps` (`crates/c3-core/src/ledger.rs:195`), and `crates/c3/src/telemetry/backfill.rs` shows backfill is a paved road; write the events once you know the fields. (O6) Make effort a randomized router arm (epsilon-exploration), so the score falls out of decisions you must make anyway. (O7) A paired design: the same brief at two tiers on the same diff - the only cheap route to identified causal data.

To choose I would need: how many usable cells you will really have in three months; whether the intake rejects unknown keys and carries a schema version; whether Astra's window share is attributable per run at all.

## Q1 - tiers and the denominator
gpt-6-astra: nothing below `high` for a run that yields a verdict; `medium` only for a mechanical reading pass over a diff you already trust; `xhigh` for core-contract/stuck only. The only evidence is nine hits at `high`; `medium` for a reading pass is an untested bet - pair it (O7) rather than assume it. glm-5.3: the three tiers are the vendor's cap (`crates/c3-core/src/effort.rs:101`), so `low`=chore, `high`=review, `max`=stuck. The denominator: none is universal. Astra's window is shared with the operator's other traffic (8 to 72 % with no bridge runs, `state.md:208`), so use the marginal change around the run, not the nominal share; GLM has no window at all, so compare on money or wall time only. Confirmed findings (option 3) is the right long-term numerator, but usefulness marks are chosen by the coordinator who chose the tier - they measure the chooser.

## Q2 - capture point, privacy, attribution
`SubagentStop` is necessary and not sufficient: it does not fire for a worker the coordinator kills or one that dies with the process, so `stopped`/`error` - the shares the table exists to show - are under-counted. Pair it with `SubagentStart` and reconcile at wave end (Start without Stop implies stopped/unknown). An Agent call's effort override is probably absent from the transcript: take effort from the coordinator or send `unknown`, never guess. Keep out: brief or prompt text, paths (`agent_transcript_path` stays local), the agent label as typed, session/agent ids (pseudonymise like `consult_ref`), the `--note` text, tool arguments, repo and cwd. Attribution: the hook sees execution, not survival. Add a coordinator-side post-hoc class - `as-delivered | reworked | superseded | unused` - and attribute primarily at the wave (did the wave pass, in how many attempts).

## Q3 - fields to add now
- `vocab_version`: the event must name the mapping that produced the tier; `CAPS_VERSION` exists locally (`crates/c3-core/src/effort.rs:5`) and has no place on the wire.
- `effort` (sent) + `effort_requested` + `effort_mapping`: z.ai maps `medium` and `high` to the single sent value `high` (`crates/c3/src/consult/orchestrate.rs:1193`), so the sent token alone cannot tell the two apart - exactly the comparison you want.
- `actor` (`reviewer|worker|coordinator`), `tier` (`haiku|sonnet|opus|fable|other`), `host` class - one event family, not two tables.
- `billing` class plus an optional window share: an absent denominator must be legal, not zero.
- `wave_id` and `attempt_index` (pseudonymous) to join rework.
Anti-breakage is permissive ingest plus a version, not more fields: the payload is a fixed struct with an exact-bytes test (`crates/c3/src/telemetry/classes.rs:267`), so accept-and-ignore unknown keys before the first new field ships.

## Q4 - scout and judge
It fails where the scout's false negative is invisible: the judge can only audit what the digest contains, and shrinking the digest drops the anchors that would let the judge contradict it. A cold-cache digest that does not name its commit lets the judge reason on a moved tree. Cap items (at most N) and per-item quote length, not bytes; demand one anchor per claim and a what-I-did-not-read coverage count; let the judge open N anchors itself; make `digest insufficient, escalate to full read` a counted outcome; and run the occasional unassisted control to measure the scout's miss rate.
