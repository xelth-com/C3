**Q1 — JSON shape.** Keep (b): canonicalise to the 5.1 shape on write, accept any on read (`ps_json.rs:26-30`). (a) is unknowable at write time; (c) breaks byte-compat with the 194 KB/184 KB evidence for no gain. Churn is bounded and non-corrupting: every append already rewrites the whole file, so a PS7-host plugin write followed by a C3 write churns once per plugin write — diff noise only. Harden: state the invariant ("C3 writes 5.1 bytes; readers accept any") in `contracts.md`, keep the byte-identity tests mandatory (`tests/contracts.rs:45-78`), and prefer pinning the plugin to Windows PowerShell 5.1 so there is one writer shape.
